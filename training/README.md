# Model Training Pipeline Scripts

This folder contains Python scripts/Jupyter Notebooks for model training:
- `data_augmentation.py`: Preprocess and expand dataset.
- `train_mobilenet_transfer.py`: Script to perform Transfer Learning on MobileNetV2 using Paddy/Cotton datasets.
- `export_to_web.py`: Script to convert trained Keras/PyTorch models to TensorFlow.js (`tensorflowjs_converter`) and ONNX.
